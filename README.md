# نظام الحضور والانصراف بالإحداثيات

تطبيق أندرويد + لوحة متابعة ويب. البصمة تعمل فقط داخل نطاق موقع العمل، والسجل يُكتب بوقت السيرفر ولا يمكن تعديله أو حذفه.

---

## ما يميّزه

| الميزة | التفاصيل |
|---|---|
| بصمة بالإحداثية | لا تعمل خارج النطاق المحدد (نصف قطر تحدده أنت) |
| كشف الموقع الوهمي | `isMock` + فحص تطبيقات Fake GPS المثبّتة + كشف الروت والمحاكيات |
| وقت السيرفر | الوقت يُكتب بـ `REQUEST_TIME` من Firestore — تغيير ساعة الجوال لا يفيد |
| ربط الجهاز | الموظف يربط جهازه مرة واحدة، وفك الربط بيدك فقط |
| سجل غير قابل للمسح | قواعد Firestore تمنع التعديل والحذف نهائياً — حتى منك |
| منع الانصراف المبكر | زر الانصراف مرفوض قبل نهاية الدوام إلا بإذنك |
| مراقبة أثناء الدوام | إذا غادر النطاق يوصلك إشعار تيليجرام فوراً مع الموقع |
| نبضة كل دقيقتين | لو أقفل التطبيق أو أطفأ الموقع تنقطع النبضة ويوصلك تنبيه |
| يعمل بعد إعادة التشغيل | المراقبة ترجع تلقائياً بعد إطفاء الجوال وتشغيله |
| بصمة الإصبع | تأكيد هوية قبل كل عملية |

## الإعداد — 6 خطوات

### 1) أنشئ مشروع Firebase
1. افتح https://console.firebase.google.com ← **Add project**
2. بعد الإنشاء: **Build ← Firestore Database ← Create database** ← اختر **Production mode** ومنطقة قريبة.
3. **Build ← Authentication ← Get started ← Email/Password** ← فعّله.

### 2) أنشئ حسابين
في **Authentication ← Users ← Add user**:
- حسابك (المدير): مثال `admin@yourname.com`
- حساب الموظف: مثال `employee1@yourname.com`

### 3) الصق قواعد الحماية
افتح `firestore.rules` من هذا المستودع، بدّل `ADMIN_EMAIL_HERE` ببريد حسابك،
ثم انسخ الملف كامل في **Firestore Database ← Rules ← Publish**.

> بدون هذه الخطوة البيانات مكشوفة. لا تتخطّها.

### 4) خذ بيانات الربط
**⚙️ Project settings ← General** ← في Your apps أضف **Web app** (أيقونة `</>`)،
ثم انسخ:
- `projectId`
- `apiKey`

### 5) اربط لوحة المتابعة
افتح صفحة اللوحة، الصق `projectId` و `apiKey`، ثم سجّل دخول بحساب المدير.
من اللوحة:
- اضغط على الخريطة لتحديد **موقع العمل** ونصف القطر
- حدّد **بداية ونهاية الدوام** وأيام العمل
- الصق **توكن بوت تيليجرام** و **Chat ID** (الخطوة التالية)
- اضغط **حفظ الإعدادات**

### 6) بوت تيليجرام للإشعارات
1. في تيليجرام ابحث عن **@BotFather** ← أرسل `/newbot` ← اختر اسم ← يعطيك **توكن**.
2. أرسل أي رسالة لبوتك الجديد.
3. افتح في المتصفح: `https://api.telegram.org/bot<التوكن>/getUpdates`
   وخذ الرقم من `"chat":{"id":‎123456789`
4. الصق التوكن والرقم في اللوحة ← **جرّب إشعار تيليجرام** للتأكد.

## تثبيت التطبيق

لا يحتاج تعديل أي كود.

1. حمّل `hudoor.apk` من تبويب **Releases**.
2. ثبّته على جوال الموظف (يحتاج السماح بالتثبيت من مصادر غير معروفة).
3. عند أول تشغيل يطلب **Project ID** و **API Key** — نفس القيمتين اللي في اللوحة.
   تُدخل مرة واحدة فقط.
4. بعدها يسجّل الموظف دخوله ببريده وكلمة مروره.

### مهم جداً عند التثبيت على جوال الموظف
- صلاحية الموقع: اختر **السماح دائماً** (Allow all the time) — بدونها تتوقف المراقبة.
- الإشعارات: اسمح بها.
- البطارية: اختر **غير مُقيّد** (Unrestricted) للتطبيق، وإلا يقتله النظام أثناء الدوام.
- على أجهزة شاومي/هواوي/أوبو: أضف التطبيق لقائمة **التشغيل التلقائي** (Autostart).

## الحدود الواقعية — اقرأها

- لا يوجد تطبيق على جهاز يملكه المستخدم يستحيل اختراقه نهائياً. هذا النظام يرفع تكلفة الغش
  إلى مستوى يحتاج هندسة عكسية للملف، ويسجّل كل محاولة بوقت السيرفر لتظهر في لوحتك.
- الطرق العادية للغش **لا تعمل**: Fake GPS، تغيير وقت الجهاز، البصمة من جوال ثانٍ،
  حذف سجل، إقفال التطبيق للتهرب من المراقبة.
- **أقوى تحصين إضافي:** فعّل **إلزام شبكة واي فاي المكتب** من اللوحة وضع BSSID الراوتر.
  الـ GPS يمكن تزييفه نظرياً، أما وجوده على شبكة الراوتر فلا.
- توكن تيليجرام موجود في إعدادات Firestore التي يقرأها التطبيق. إذا أردت إخفاءه تماماً
  يمكن إضافة وسيط مجاني (Cloudflare Worker) لاحقاً.
- اطّلع على الأنظمة المعمول بها لديك بخصوص إشعار الموظف بتتبّع موقعه أثناء الدوام،
  وأبلغه بذلك كتابياً — هذا في مصلحتك قبل مصلحته.

## بنية البيانات في Firestore

| المجموعة | الوصف |
|---|---|
| `config/workplace` | الإحداثية، النطاق، أوقات الدوام، إعدادات الإشعار |
| `attendance` | كل بصمة حضور وانصراف (إضافة فقط) |
| `events` | المغادرة، الرجوع، محاولات التلاعب (إضافة فقط) |
| `status/{uid}` | الحالة الحيّة والنبضة |
| `employees/{uid}` | ربط الجهاز |
| `perm/{uid}` | إذن الانصراف المبكر |
| `requests` | طلبات الاستئذان |
